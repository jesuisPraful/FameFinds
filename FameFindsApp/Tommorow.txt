Salesforce Basics

Salesforce is a cloud-based CRM that helps businesses manage customer data, sales, marketing, and support in one place.
Customer 360: Single view of each customer for personalized service.
Key Clouds: Sales Cloud, Service Cloud, Marketing Cloud, Commerce Cloud.
Low-Code Platform: Build custom apps and automate tasks without heavy coding.
Ecosystem: Salesforce + partners + customers + Trailblazer community.
Result: Better customer experience, shared data, and faster innovation.

Declarative vs. Imperative on Salesforce (Short)

Declarative (Point-and-Click):
Build with clicks using tools like Flow, Process Builder, and Validation Rules.
Faster to create, easier to maintain, upgrades automatically.
Best for most business logic and automation.

Imperative (Code):
Write Apex, JavaScript, or custom Lightning components.
Needed for complex logic, heavy integrations, or unique UI.
Requires developer skills and more testing.

Best Practice:
Start declarative first; use code only when clicks can’t handle the requirement.

The ecosystem is the community around Salesforce, including:
Customers: Businesses and nonprofits using Salesforce.
